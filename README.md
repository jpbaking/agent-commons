# Agent Commons

**One canonical source, every coding-agent harness.**

Agent Commons is an umbrella workspace for a family of reusable AI-agent
toolkits — portable [Agent Skills](https://agentskills.io/), always-on rules,
and a merge-aware agent install contract that works identically across
**Google Antigravity CLI (`agy`)**, **OpenAI Codex**, **Anthropic Claude
Code**, **Google Gemini CLI**, **Cline**, and **OpenCode**.

Every toolkit here follows the external
[Portable Agent Authoring](https://github.com/jpbaking/portable-agent-authoring)
guides — in particular
[Agent toolkit repositories](https://github.com/jpbaking/portable-agent-authoring/blob/main/agent-toolkit-repositories.md),
the de facto standard for building and installing a toolkit. Family-specific
additions are in [docs/conventions.md](./docs/conventions.md):

- canonical skills live in `.agents/skills/`; `.claude/skills/` contains
  generated byte-identical mirrors for contributors; `.gemini/settings.json`
  points Gemini CLI at `AGENTS.md`. Reusable global rule bodies live in
  `rules/shared/`;
- installs are **agent-guided only** — each repo ships an `AGENT-INSTALL.md`
  your agent follows after cloning the repo with **git and your existing
  credentials** (no raw-file or archive downloads, so it works behind
  enterprise GitHub authentication); there are no install scripts. This
  umbrella ships one too —
  [AGENT-INSTALL.md](./AGENT-INSTALL.md) — for installing several toolkits
  in a single audited pass, after it asks you which ones you want;
- every toolkit installs **user-global**; installs never write into
  consuming projects (not even `.gitignore`). Projects commit only truth —
  `DOX.md` trees, the root `AGENTS.md` / `CLAUDE.md` / `.gemini/settings.json` anchors carrying the
  DOX shim (created by `dox-init` / `dox-upgrade`), `.goal-ledger/` records,
  `compose-helper.*`, generated agentic tests.

## The toolkits

| Submodule | What it gives your agent |
|---|---|
| [dox](https://github.com/jpbaking/dox) | A `DOX.md` documentation-tree framework: precise project context, walked root-to-leaf before every edit |
| [goal-ledger](https://github.com/jpbaking/goal-ledger) | A git-tracked execution record for multi-phase work: crash recovery, handoff, branch isolation, safe squash |
| [agentic-tests](https://github.com/jpbaking/agentic-tests) | A disciplined test engineer: behavior-locking unit tests, mutation checks, frozen-suite refactoring |
| [playwright-fieldkit](https://github.com/jpbaking/playwright-fieldkit) | Hands and eyes on the web: crawl, debug, record, and test live sites via deterministic Playwright scripts |
| [compose-helper](https://github.com/jpbaking/compose-helper) | A safe `docker compose` wrapper plus the rules that stop agents from wiping volumes or hanging on logs |

Each submodule is an independent repository with its own releases; this
umbrella pins known-good revisions of all five.

## Quick start

Clone with submodules:

```sh
git clone --recurse-submodules https://github.com/jpbaking/agent-commons.git
# or, in an existing clone:
git submodule update --init
```

Then install any single toolkit by pasting its README's agent prompt into
your coding agent, or install several at once with this umbrella's
`AGENT-INSTALL.md`:

```
Install Agent Commons toolkits. Using git with my existing credentials (do not
download raw files or archives), clone
https://github.com/jpbaking/agent-commons at tag v4.1.1 with --depth 1
--recurse-submodules --shallow-submodules into a new temporary directory
outside any project. Then read AGENT-INSTALL.md from that clone and follow it
exactly. Ask me which toolkits and which harnesses before installing anything,
merge with—never blindly overwrite—any existing global instruction files, and
report every file you created or changed.
```

This prompt pins umbrella release `v4.1.1`, which pins each toolkit's matching
release. To install another release, change the tag; to track the default
branch, drop `at tag v4.1.1`. Your agent will execute the instructions in the
cloned contracts and writes only to user-global paths (`~/.agents/skills/`,
`~/.claude/skills/`, `~/.gemini/antigravity-cli/skills/`, `~/.agents/rules/`,
and marker-guarded blocks in your global instruction files).

See [docs/getting-started.md](./docs/getting-started.md) for the details.

## Layout

```text
AGENT-INSTALL.md           # family-level agent-guided install (opt-in per toolkit)
AGENTS.md                  # authoritative umbrella repository guidance
CLAUDE.md                  # @AGENTS.md bridge for Claude Code
.gemini/settings.json      # points Gemini CLI at AGENTS.md
README.md                  # this file
docs/                      # umbrella user guides
<toolkit>/                 # five submodules, one per toolkit
```
